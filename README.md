# Car Trading Company Database System

## Project Description

This project is a database application designed for a car trading company that sells cars and spare parts through multiple branches.

The system provides different interfaces for **managers and customers**. The manager interface allows the manager to manage the company's data and operations, while the customer interface allows customers to browse available cars and spare parts.

## Main Features

* Manager interface for managing company data and operations.
* Customer interface for browsing available cars and spare parts.
* Management of cars and spare parts.
* Management of branches, employees, suppliers, and warehouses.
* Management of sales and purchase transactions.
* Database integration for storing and retrieving system data.
* ER Diagram showing the database entities and relationships.
* SQL scripts for creating and managing the database.

## Technologies Used

* **Java**
* **JavaFX** – for developing the graphical user interfaces.
* **SQL** – for database creation and queries.
* **ER Diagram** – for designing the database structure.

## Project Structure

The project includes:

* **Manager Interface** – for managing the company's operations and data.
* **Customer Interface** – for browsing cars and spare parts.
* **ER Diagram** – represents the entities and relationships in the database.
* **SQL Files** – contain the database creation and SQL queries.

## Database Design

The database was designed using an ER Diagram that represents the main entities, their attributes, and the relationships between them.

The SQL files contain the database implementation and the required queries for managing the system.
